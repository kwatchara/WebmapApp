# WebmapApp

Web map application project.

## Structure

- `frontend/` — Vite + TypeScript (vanilla-ts) frontend
- `test.ipynb` — Python notebook (data / experimentation)

## Frontend — getting started

```bash
cd frontend
npm install
npm run dev      # start Vite dev server → http://localhost:5173/
npm run build    # production build
```

## Requirements

- Node.js 18+ (developed on v22)
- Python 3.x (virtualenv in `.venv/`, not tracked)
